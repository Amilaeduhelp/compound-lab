භාවිතයට උපදෙස් · Instructions for Use

සිංහල

  1. මූලද්‍රව්‍යයක් මත click/tap කරන්න — එය තෝරාගැනේ.
  2. එයට සංයෝග විය හැකි මූලද්‍රව්‍ය teal පාටින් highlight වී පෙන්වයි; අනෙක් සියල්ල බොඳ වී පෙනේ.
  3. ඉන්පසු "drop A" හෝ "drop B" කොටුව මත click/tap කර මූලද්‍රව්‍යය එහි තබන්න.
  4. එලෙසම දෙවන මූලද්‍රව්‍යයක් තෝරා අනෙක් කොටුවට තබන්න.
  5. Desktop පරිගණකයක නම් mouse එකෙන් drag කර කොටුවලට drop කළ හැක.
  6. කොටු දෙකම පිරුණු විට, සෑදෙන සංයෝගය සහ එහි විස්තරය "=" ලකුණට පසුව පෙන්වයි.
  7. නැවත ආරම්භ කිරීමට "Reset" බොත්තම click කරන්න.

English

  1. Click or tap an element to select it.
  2. Elements it can react with are highlighted in teal; every other element dims out.
  3. Tap either the "drop A" or "drop B" slot to place the selected element there.
  4. Select a second element the same way and place it in the other slot.
  5. On desktop, you can also drag an element directly onto a slot.
  6. Once both slots are filled, the resulting compound and its explanation appear after the "=" sign.
  7. Tap "Reset" to clear both slots and start again.
